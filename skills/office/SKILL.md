# Office

## 选择流程

用命令行程序或脚本提取, 修改和转换 Office 文件. `read` 查看提取后的文本, PDF 或图片, `write` 和 `edit` 操作脚本及必要的 XML 文件.

先区分读取, 新建, 编辑和转换. 只读任务不写回源文件或主动重算. 未要求重新设计时沿用原文件或指定模板.

只读取本次涉及的格式参考:

| 格式 | 参考 |
| --- | --- |
| Word | `skill://office/references/word.md` |
| Excel | `skill://office/references/excel.md` |
| PowerPoint | `skill://office/references/powerpoint.md` |

其他参考按需读取:

- 版式检查, PDF 导出或旧格式转换: `skill://office/references/rendering.md`.
- 格式参考中的库无法满足编辑或保留要求: `skill://office/references/ooxml.md`.
- 执行因缺少依赖受阻: `skill://office/references/environment.md`.

## 执行

直接使用现有环境, 不预先检查或调整依赖.

1. 按需提取内容或查看页面, 不为文字读取先渲染整个文件. 编辑前定位段落, 表格, 单元格或形状, 不能只凭页面图像定位.
2. 内容来自用户要求和来源材料. 缺少关键事实时询问或明确留空. 模板填充后, 仅保留用户明确要求保留的占位项.
3. 明确修改范围和预期数量. 文本替换前校验命中数, 不符预期时停止并处理歧义.
4. 用格式参考中的库编写脚本. 复杂任务维护一个可重跑脚本, 避免多个内容分叉的版本.
5. 在工作副本上修改必要对象, 保持文字, 表格和图表可编辑. 不用整页截图或从提取文本重建的文件冒充保留原件的编辑结果.
6. 核对实际变更的数量和位置, 完成格式参考中的内容检查. 新建文件或影响布局的编辑还需渲染检查, 修复后复查受影响范围.
7. 验证后保存到目标路径. 覆盖源文件前检查源版本是否变化, 不覆盖外部修改.

## 交付

返回目标文件, 修改摘要和必要限制. 未发生变更时说明原因. 中间文件和脚本仅按用户需要交付.

明确报告未验证项. 保存成功不代表公式正确, 高级对象完整保留或版式通过检查.
