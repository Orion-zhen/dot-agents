# 渲染与转换

默认用 LibreOffice 转成 PDF, 再用 `read` 查看所需页面. 用户指定其他引擎时核对接口和导出行为, 不反复探测其他引擎. 渲染用于视觉检查或格式转换, 不是文字提取的前置步骤.

## 导出 PDF

将输入替换为实际文件:

```bash
work_dir=$(mktemp -d)
soffice -env:UserInstallation="file://$work_dir/profile" \
  --headless --convert-to pdf --outdir "$work_dir" input.docx
```

以上为 POSIX shell 示例. Windows 使用当前环境中的 LibreOffice 路径和等价参数.

- 每次转换使用独立输出目录和 LibreOffice 配置目录, 避免覆盖同名结果和并发配置冲突.
- 设置执行超时. 失败后先检查错误和输出文件, 再决定是否重试或更换引擎. 不终止所有 Office 进程.
- 确认本次生成的 PDF 能打开, 不仅检查退出码. 用 `read` 分页查看, 源文件未变时复用 PDF, 变化后重新生成.
- 用户要求 PDF 时, 将验证后的 PDF 保存到目标路径. 其他情况下 PDF 仅作检查用中间文件. 完成后清理本次临时资源.
- 含宏, 活动内容或外部依赖时, 先确认导出不会执行代码或刷新外部资源. 无法确认时停止自动转换并说明限制.

## 视图边界

| 格式 | 检查重点 |
| --- | --- |
| Word | 表格跨页, 页眉页脚, 字体和换行. 内容增删可能影响后续分页. |
| PowerPoint | 幻灯片顺序, 对象布局和文字. 缩略图不能代替单页细节检查. |
| Excel | 打印范围, 缩放和分页. PDF 不能证明打印区域外没有内容. |

- Word 含修订或批注时, 明确检查正文还是审阅记录并核对导出视图. 不擅自接受修订, 不将未显示的批注视为不存在.
- PowerPoint 先检查隐藏幻灯片. 如需与源文件逐张对应, 核对导出设置, 页数和顺序. 备注和动画另行检查, 静态页面不能完整表达它们.
- Excel 保留原有打印设置, 必须调整时仅修改工作副本并说明. 导出可能重算内存中的结果. 如需查看已有计算结果, 先确认导出不会重算, 无法确认时说明页面值可能不同于源文件缓存. 页面值不能证明源文件缓存已更新或公式正确.

## 视觉检查

- 字体可用, 中文和特殊字符没有缺字.
- 文字, 数字和图表没有裁剪, 非预期重叠或不可读的缩放.
- 表格宽度, 图片比例, 间距和对齐符合要求.
- 已有文件使用相同引擎比较修改前后, 区分本次修改与渲染器差异.
- 达到正确和可读的要求后停止, 不反复微调无关样式.

文本提取和结构检查不能替代视觉检查.

## 旧格式转换

`.doc`, `.xls`, `.ppt` 先转换为对应的 `.docx`, `.xlsx`, `.pptx` 工作副本. 用 `--convert-to` 指定目标格式, 输出到独立目录, 再按格式参考处理.

转换可能改变样式, 公式或高级对象. 保留原件并比较结果. 加密文件需用户提供可访问副本或授权解密, 不绕过保护.
