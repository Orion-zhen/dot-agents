# OOXML 局部修改

仅在格式参考中的库无法满足编辑或保留要求时使用. `.docx`, `.xlsx`, `.pptx` 是包含 XML, 媒体和关系文件的 ZIP 包.

## 定位与修改

1. 在工作副本中列出部件, 定位目标对象及其关系, 不输出全部 XML.
2. 从内容类型和关系文件解析目标, 不将文件编号视为文档展示顺序.
3. 用能保留命名空间的 XML 解析器, 如 `lxml`, 修改必要节点. 保留未知节点, 属性和未涉及的部件, 不做无关格式化或全局字符串替换.
4. 增删部件时同步维护 `[Content_Types].xml`, `.rels` 和引用标识. 删除前检查其他对象是否仍在引用.
5. 从包根目录重新打包到新文件, 不增加外层目录. 向旧 ZIP 追加不会移除已删除的部件.

解析脚本应限制解压资源, 拒绝越界路径和危险符号链接, 禁用 XML 外部实体及网络解析. 不执行宏, 嵌入程序或自动刷新外部资源.

## 各格式要点

### Word

文字可能分布在多个 `<w:r>` 和 `<w:t>` 中. 跨文本片段替换时保留未修改内容及样式, 不合并格式不同的片段.

文本插入和删除修订使用 `<w:ins>` 和 `<w:del>`, 删除文字使用 `<w:delText>`. 作者, 时间和标识须符合审阅要求, 不伪造身份. 删除段落标记也会影响最终结构, 不能只处理可见文字.

批注的正文锚点, 部件和关系须一致. 仅写入批注文本不足以保证显示. 没有经过验证的实现时先确认格式要求, 不猜测关系结构.

### Excel

工作表名称通过工作簿关系映射到部件. 单元格可能引用共享字符串, 样式或公式, 修改时区分类型. 修改共享字符串可能影响多个单元格.

XML 修改不自动计算公式或更新缓存. 公式或依赖变化后按 [Excel 重算流程](skill://office/references/excel.md) 处理.

### PowerPoint

幻灯片顺序由演示文稿中的列表和关系决定. 复制时检查布局, 图片, 图表, 备注和嵌入对象的关系. 明确共享与独立复制的部件, 避免修改副本时影响原页.

## 验证

- 检查 ZIP 能打开, XML 能解析, 内部关系目标存在, 内容类型和标识一致.
- 用目标格式库或阅读器重新打开结果. 有适用的 XML 模式校验器时运行校验.
- 比较修改前后的部件和目标内容, 确认没有无关变化.

结构检查, 阅读器打开和视觉检查覆盖不同问题. 是否需要渲染按主文判断. 不用重建文件掩盖保留失败.
