# 性能问题

性能调查的核心是确定主导退化的实际原因, 并在保持业务语义和正确性的前提下改善它.

性能结论必须基于可比较的工作负载和基线. 单次运行、局部耗时或代理指标不足以证明整体性能变化.

不要从最容易修改的位置开始优化, 也不要为了改善指标而:

- 改变未被允许改变的业务行为
- 降低结果质量或正确性
- 跳过必要检查
- 将成本转移到其他关键资源或路径
- 只优化不具代表性的样本

局部热点与整体退化可能不是同一问题. 优化后应重新检查主导成本, 而不是仅确认被修改的局部指标改善.

当连续修改没有改变主导成本, 或改善始终处于自然波动范围内时, 停止当前优化方向, 重新审视测量方法、工作负载代表性和瓶颈假设.

报告性能修复时, 同时说明指标改善、测量条件、业务行为是否保持, 以及产生的资源或质量权衡.
